How to Win

  1. Each player starts with exactly 1,000 credits.
  2. The match lasts exactly 3 minutes.
  3. Use your credits in Blackjack, Slots, and Roulette.
  4. Bets are deducted before a game resolves; winning payouts are added automatically.
  5. When the clock reaches zero, the player with the higher balance wins.

Credits have no cash value. This is a skill-and-luck game using fictional currency.
